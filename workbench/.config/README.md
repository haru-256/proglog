### `cfssl gencert` の役割

`cfssl gencert` は、**新しいデジタル証明書を生成する**ためのコマンドです。

このコマンドの主な役割は、既存の認証局（CA）に、新しい証明書の発行を要求し、その結果として**署名済みの証明書**と、それに対応する**秘密鍵**を出力することです。

コマンドを実行すると、通常は `cfssljson` というヘルパーコマンドにパイプ（`|`）でつなぎ、以下の3つの主要なファイルが出力されます。

1. **CSR (証明書署名要求)**
2. **秘密鍵 (Private Key)**
3. **証明書 (Certificate)**

ここでは、`cfssljson -bare server` のように実行し、`server` というプレフィックスでファイルが出力されたと仮定して解説します。

-----

### 出力される3つの主要ファイル

#### 1\. `server.csr` (証明書署名要求)

* **役割**: 認証局（CA）に対して「この内容で証明書を発行してください」とお願いするための\*\*「申請書」\*\*です。
* **中身**:
  * **公開鍵**: 同時に生成される秘密鍵とペアになる鍵。
  * **識別情報**: 証明書に記載してほしいドメイン名 (`www.example.com`など) や組織名、国名といった情報。
* **解説**:
    `cfssl gencert`に認証局の情報（`-ca`と`-ca-key`）を渡して実行した場合、このCSRはコマンドの内部処理で使われる**中間生成物**となります。コマンドは、このCSRの内容を元に、最終的な証明書（`server.pem`）を自動で生成します。そのため、最終的にはこのファイルは不要になることが多いですが、証明書がどのような情報で発行申請されたかを確認するために役立ちます。

#### 2\. `server-key.pem` (秘密鍵)

* **役割**: **【最も重要】** 発行された証明書（`server.pem`）とペアになる秘密の鍵です。これは、あなたのサーバーだけが持つ**「金庫の鍵」**に相当します。
* **中身**: `-----BEGIN EC PRIVATE KEY-----` のようなヘッダーで始まる、暗号化された長い文字列（鍵データ）。
* **解説**:
    この秘密鍵は、**絶対に外部に漏らしてはいけません。** もしこれが漏洩すると、第三者があなたのサーバーになりすましたり、暗号化された通信を解読したりすることが可能になってしまいます。このファイルは、サーバーの安全な場所に厳重に保管し、証明書と一緒にウェブサーバーなどに設定します。

#### 3\. `server.pem` (証明書)

* **役割**: **【最終成果物】** 認証局があなたのCSR（申請書）を承認し、その認証局の秘密鍵でデジタル署名を行った**「公的な身分証明書」**です。
* **中身**:
  * CSRに含まれていた情報（公開鍵、ドメイン名など）。
  * **発行者（Issuer）**: 署名を行った認証局の情報。
  * **有効期間（Validity）**: この証明書がいつからいつまで有効か。
  * **デジタル署名**: この証明書が本物であり、改ざんされていないことの証拠。
* **解説**:
    これが、実際にクライアント（ブラウザなど）に提示されるファイルです。クライアントは、この証明書を受け取り、署名した認証局が信頼できるかどうかを検証します。ウェブサーバーなどには、この証明書ファイル (`server.pem`) と、対応する秘密鍵ファイル (`server-key.pem`) の両方を設定する必要があります。

-----

### まとめ：各ファイルの役割と重要度

| ファイル名 | 役割（一言で言うと） | 重要度 | 誰に渡すか？ |
| :--- | :--- | :--- | :--- |
| `server.csr` | 認証局への **「申請書」** | 中 | 認証局 (CA) (※`cfssl gencert`では内部処理で使われる) |
| `server-key.pem`| 証明書とペアになる **「金庫の鍵」** | **極めて高い** | **誰にも渡さない（サーバーに厳重保管）** |
| `server.pem` | 認証局発行の **「身分証明書」** | 高い | サーバーに設定し、通信相手のクライアントに提示 |

`cfssl gencert`は、これら一連のファイルを効率的に生成するためのコマンドです。特に、**秘密鍵 (`-key.pem`)** は自分で管理する最も重要な資産であり、**証明書 (`.pem`)** はその身元を公的に証明するためのものである、と覚えておくと良いでしょう。
